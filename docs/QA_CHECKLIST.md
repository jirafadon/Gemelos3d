# Checklist de verificación de Gemelos 3D

## Flujo principal

- [ ] Crear una palabra desde el Taller.
- [ ] Confirmar que `0 mm` conserva el ancho natural.
- [ ] Confirmar que un ancho positivo representa el ancho total de la palabra.
- [ ] Confirmar que se conserva el orden de los caracteres.
- [ ] Confirmar que la generación no rota ni reordena automáticamente.
- [ ] Confirmar que las piezas que exceden la cama se dividen físicamente.
- [ ] Confirmar que las piezas divididas aparecen en camas independientes.
- [ ] Exportar STL completo.
- [ ] Exportar STL por cama.

## Proyectos

- [ ] Crear un proyecto desde Crear con IA.
- [ ] Crear un proyecto desde SVG → 3D.
- [ ] Crear un proyecto desde Importar modelo.
- [ ] Abrir `proyectos.html` y continuar un proyecto existente.
- [ ] Abrir `app.html?project=ID` y comprobar que carga el proyecto correcto.
- [ ] Guardar y volver a abrir la configuración.

## Importación

- [ ] Probar STL.
- [ ] Probar OBJ.
- [ ] Probar GLB.
- [ ] Probar GLTF.
- [ ] Probar 3MF.
- [ ] Verificar unidades y escala antes de fabricar.

## Referencia NeonFlex

- [ ] Comparar el flujo de creación de texto 3D.
- [ ] Comparar controles de ancho total, alto y grosor.
- [ ] Comparar claridad visual del paso Crear → Configurar → Revisar → Taller.
- [ ] No copiar código ni asumir funciones del sitio externo sin inspección verificable.
