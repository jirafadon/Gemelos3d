🤖 Crear con IA

Creá un modelo desde una descripción, un dibujo o una imagen. Cuando esté listo, lo podés llevar al Taller 3D para medidas, fabricación y exportación.

💬 Texto → 3DDescribí qué querés fabricar con palabras.
✏️ Dibujo → 3DPrepará un boceto y transformalo en un modelo.
🖼️ Imagen → 3DSubí una referencia visual para generar la forma.
PNG, JPG o WebP
✏️ Dibujo → 3D
El módulo de dibujo tendrá su propia sección. Desde acá vas a poder traer el dibujo cuando esté listo.
Listo para crear. La generación real con IA se conectará desde el servidor, manteniendo la clave de API fuera del navegador.

➡️ Después de generar

El resultado seguirá este camino: modelo 3D → llevar al Taller → medidas → fabricación → costos → exportación. Esta pantalla no reemplaza ni modifica el Taller existente.
